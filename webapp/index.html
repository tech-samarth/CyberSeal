Full Forensic Feature Set

🔐
SHA-256 Cryptographic Hashing
Every piece of evidence — screenshots, metadata, DOM snapshots — gets a unique SHA-256 fingerprint. Any alteration produces a completely different hash, making tampering instantly detectable.
CRYPTO CORE
⛓
Blockchain Anchoring
Evidence hashes are anchored on Polygon (Mumbai testnet) or Ethereum, creating an immutable timestamp proof. Even if all local copies are deleted, the hash lives on the blockchain forever.
POLYGON / ETH
🔒
AES-256-GCM Encrypted Vault
All evidence packages are encrypted with AES-256-GCM before storage. Each capture gets a unique encryption key. Firebase cloud vault stores encrypted blobs — even Anthropic can't read them.
FIREBASE
